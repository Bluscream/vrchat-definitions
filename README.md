# VRChat Definitions

Centralized repository containing definitions for VRChat launch arguments, environment variables, registry keys, and config schema.

## Files

- `cmdline.csv`: VRChat command line flag definitions
- `env.csv`: Environment variable definitions (Proton, DXVK, VKD3D, Mesa, Vulkan, etc.)
- `registry.csv`: VRChat Windows Registry setting definitions
- `config.schema.json`: JSON Schema for VRChat `config.json`
