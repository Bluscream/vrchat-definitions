--osc=PORTS string Configures OSC ports: inPort:senderIP:outPort format

e.g. --osc=9000:127.0.0.1:9001. Required for VRCOSC and other OSC tools		 9000:127.0.0.1:9001 ^\d{1,5}:[0-9.]+:\d{1,5}$
--fps=FPS int Sets the target frame rate cap for VRChat rendering

Unity engine cap; higher = more CPU/GPU load		 90 ^(1[5-9]|[2-9]\d|[1-2]\d{2}|3[0-5]\d|360)$
--affinity=MASK string Sets CPU thread affinity hex bitmask for the VRChat process — for AMD CPU optimization

FFFF=16 threads; wrong value causes crashes. Advanced/AMD only		 none ^[0-9A-Fa-f]{1,16}$
--process-priority=LEVEL int Sets the OS process priority level for VRChat

-2=Idle,-1=Below Normal,0=Normal,1=Above Normal,2=High		 -1 ^-?[0-2]$
--no-steam switch Bypasses Steam client requirement when launching via launch.exe directly

Only works with the launcher.exe direct launch method		 none
--profile=NAME string Launches with a separate isolated settings profile directory

Creates a subfolder in AppData for isolated settings		 default ^[A-Za-z0-9_\-]{1,64}$
--watch-world=ID string Loads a specific world by ID on startup (e.g. wrld_...)

Useful for testing — skips startup world loading		 none ^wrld_[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$

e.g. wrld_abc:12345~region(us)		 none ^wrld_[0-9a-f\-]+:[0-9a-zA-Z~()]+$
