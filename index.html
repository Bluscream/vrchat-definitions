VRChat Definitions Documentation

Centralized schema and parameter definitions for VRChat launch flags, environment variables, registry keys, and config.json.

Command Line Flags

cmdline.csv

Unity standalone player and VRChat debug startup flags (--fps, --osc, --affinity...)

Environment Variables

env.csv

Proton, Wine, DXVK, VKD3D, Mesa, and Vulkan performance environment variables.

Registry Settings

registry.csv

Windows registry keys under HKCU\Software\VRChat\vrchat (Proton system.reg).

Config Schema

config.schema.json

JSON Schema for VRChat client %APPDATA%\LocalLow\VRChat\VRChat\config.json
